# Цитадель v46 — удаление менеджеров Наблюдателем

Изменено:
- Наблюдатель теперь может полностью удалить менеджера.
- При удалении удаляются:
  - сам аккаунт менеджера;
  - все его проекты;
  - его настройки;
  - блокнот;
  - сообщения;
  - активные сессии менеджера.
- Добавлено подтверждение перед полным удалением.
- Менеджер «Александр» удалён из начальных данных.
- Добавлена миграция, которая удаляет «Александр» также из уже сохранённой общей базы/локального кэша при загрузке.

ВАЖНО:
Чтобы удаление работало в общей базе, обязательно замените Apps Script на
`google_apps_script_backend.gs` из v46 и выпустите новую версию deployment:
Deploy → Manage deployments → Edit → New version → Deploy.
